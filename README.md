# Data structures

Efficient implementation of data structures I need for coding problems so I don't have to use Python anymore (even though Python is pretty good).

## Contents

- [rbtree](rbtree/README.md) - Red Black tree implementation, for efficient writes and sorted iterations. Major C++ compilers provide implementations for `std::set` and `std::map` using a red black tree. 

The `tree` package was the starting implementation and is currently being deprecated.
